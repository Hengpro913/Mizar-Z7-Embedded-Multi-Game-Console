# Mizar-Z7-Embedded-Multi-Game-Console
Mizar Z7 is a Zynq-7020 FPGA game console with a PS/PL architecture. The PL handles four games, collision detection, video timing and HDMI/DVI output; the PS supports startup and keyboard injection. It outputs 480×320 at 60 Hz, supports OpenMV vision control, and uses reusable input and timing design.
